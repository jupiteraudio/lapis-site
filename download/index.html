Lapis Bridge

A small program that runs on your own computer and lets Lapis control your hardware. Version 2.26.0.

Install in three steps
  1. Download a file below and start it. The bridge window prints a pairing code.
  2. Open Lapis, click the bridge button at the top right, and type the code.
  3. Leave the bridge running while you work. Close it to disconnect.

No Node.js needed (standalone): download the zip for your system and unzip it. macOS Apple Silicon · macOS Intel · Windows · Linux. Checksums are on the release page. On macOS and Linux, open Terminal in the unzipped folder and run chmod +x lapis-bridge-* once, then start it with ./lapis-bridge-macos-arm64 (or lapis-bridge-macos-x64, lapis-bridge-linux-x64); if macOS blocks it, run xattr -d com.apple.quarantine lapis-bridge-macos-* once first. On Windows, double-click lapis-bridge-windows-x64.exe; at the SmartScreen warning choose More info, then Run anyway.

Or with Node.js 18 or newer (free, from nodejs.org). The simplest start on every system: open Terminal (macOS) or Command Prompt (Windows) and run cd Downloads, then node lapis-bridge.cjs. On macOS a downloaded .command file will not open until you run chmod +x Start-Lapis-Bridge.command once.

What it can and cannot do

The bridge only answers this computer (127.0.0.1), needs the pairing code for every request, and writes to hardware only after you confirm in Lapis. Read-only mode is available in its settings.
